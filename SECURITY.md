# Security Policy — Meta-Orgsuite

## Reporting
Open a private security advisory on this repository.

## Privacy & Security Principles
- All conversation tracking is explicit and user-initiated.
- No external credentials or API keys are stored in this repository.
- Cross-AI delivery templates contain no secrets.
- Branding assets are public and safe for profile use.

Orgsuite is designed as a privacy-first unified AI hub for business operations.
